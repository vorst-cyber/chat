# JECKGPT – AI Pribadi Tanpa Sensor

JECKGPT adalah antarmuka chat berbasis web yang menggunakan **Google Gemini API** untuk memberikan respons AI yang **tidak disensor** (safety settings dinonaktifkan). Dibangun murni dengan HTML, CSS, dan JavaScript (ES Modules).

## Fitur
- 💬 Chat real-time dengan Gemini AI
- 🔒 Tanpa sensor konten (BLOCK_NONE)
- 💾 Riwayat chat tersimpan di localStorage
- 📝 Dukungan Markdown dasar (bold, italic, code, list, dll)
- 📤 Ekspor chat ke file .txt
- 🗑️ Hapus percakapan
- 📱 Responsif

## Prasyarat
- API Key dari [Google AI Studio](https://aistudio.google.com/)
- Browser modern (Chrome, Firefox, Edge, Safari)

## Instalasi & Penggunaan
1. Clone atau unduh repositori ini.
2. Buka `config.js` dan ganti `YOUR_GOOGLE_API_KEY_HERE` dengan API Key Anda.
3. Jalankan dengan membuka `index.html` di browser (tidak perlu server).
4. Mulai chatting!
